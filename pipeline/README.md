# pipeline

事件流 → 教程文档的处理链，按顺序实现：

| 模块 | 职责 | 状态 |
|---|---|---|
| `frames.py` | 读取事件流，合并连续事件，剔除无用帧，输出步骤列表 | 待实现 |
| `annotate.py` | 裁剪焦点区域，画红框 / 箭头 / 序号 | 待实现 |
| `render.py` | 套模板输出 Markdown / docx | 待实现 |

## 输入

扩展导出的 `events.json`（可从扩展页「检查视图」控制台复制，或后续加一键导出）。

## 输出

```
output/
  steps/001.webp
  steps/002.webp
  tutorial.md
```

## 约定

- 所有截图坐标统一按 `dpr` 换算后再使用
- 步骤文字由模板生成，允许人工在确认页修改
