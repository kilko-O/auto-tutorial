# pipeline

事件流 → 教程文档的处理链，按顺序实现：

| 模块 | 职责 | 状态 |
|---|---|---|
| `frames.py` | 读取事件流，合并连续事件（同框多次输入合并），归一化标签，合并同控件重复帧；输入类具体值不进教程（密码打码）；下拉框保留选项；标记疑似游离点击步骤，输出步骤列表 | 已实现 |
| `annotate.py` | 裁剪焦点区域，按元素真实宽高画红框与序号，框外压暗；按复核页保存的马赛克区域做高斯模糊；缺图生成占位标注图；沿用复核页调整过的红框坐标 | 已实现 |
| `render.py` | 套模板输出 Markdown / Word(docx) / 静态 HTML；另出复核页（改文案、删步、调序、红框拖动缩放、马赛克、缩略导航、疑似标黄） | 已实现 |

## 输入

扩展录制结束后自动导出的 `events.json`，以及同目录下按 `00N_<时间戳>.png` 命名的截图。

## 输出

```
output/
  steps/001.png
  steps/002.png
  steps.json        # 中间结果，便于排查与人工修改
  tutorial.md
  tutorial.docx     # --format docx / both / all 时生成（需 python-docx）
  tutorial.html      # --format html / all 时生成
  review.html        # 人工复核页：改文案、删步、调序、红框拖动缩放、拖框打马赛克、缩略导航，导出 steps.json 后用 --steps 二次成文
```

## 约定

- 所有截图坐标统一按 `dpr` 换算后再使用
- 输入类步骤不在教程里写具体值：密码类（标签含 密码 / password / pwd 等）打码为 `••••••`，其余输入框的真实值在中间结果里清空，文案按标签写成「输入账号 / 学号…」；下拉框（`tag=select`）保留所选选项，文案写成「选择【选项】」
- 图片隐私不做自动猜测遮盖：需要隐藏的内容由复核页人工框选马赛克，区域坐标随 `steps.json` 保存，二次成文时复现
- 复核页调整过的红框坐标存于步骤 `box`（裁剪图相对物理像素），二次成文直接沿用；疑似游离点击步骤用 `suspect` 标记，复核页标黄
- 步骤文字由模板生成，可在复核页（`review.html`）修改后用 `--steps` 二次成文
